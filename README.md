## 📖 Project Overview

This is my personal portfolio website showcasing my academic achievements, technical skills, and professional projects. Built as a full-stack MERN application, it demonstrates my proficiency in modern web development.

### ✨ Features

#### 🖥️ Frontend
- **React.js** with functional components and hooks
- **Framer Motion** for smooth animations
- **Responsive design** for all devices
- **Interactive UI** with modern aesthetics

#### ⚙️ Backend
- **Node.js & Express.js** RESTful API
- **MongoDB** database integration
- **CRUD operations** for project management
- **CORS** enabled for cross-origin requests
